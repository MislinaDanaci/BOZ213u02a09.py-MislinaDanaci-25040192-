# 2.6.9 LAB - Basit Girdi/Çıktı ve Dört İşlem Uygulaması

Bu depo, **BOZ213** dersi kapsamında geliştirilen `2.6.9LAB.py` Python laboratuvar çalışmasını içermektedir. Uygulama, kullanıcıdan iki adet ondalıklı sayı (`float`) alarak bu sayılar üzerinde temel dört aritmetik işlemi gerçekleştirir ve sonuçları ekrana yazdırır.

## Özellikler

- Kullanıcıdan `input()` ve `float()` fonksiyonları aracılığıyla iki ondalıklı sayı (**A** ve **B**) alır.
- Girilen sayılar üzerinde aşağıdaki işlemleri hesaplar:
  - **Toplama:** `A + B`
  - **Çıkarma:** `A - B`
  - **Bölme:** `A / B`
  - **Çarpma:** `A * B`
- Tüm işlem sonuçlarını ve kapanış mesajını konsola yazdırır.

## Gereksinimler

- Python 3.x (Herhangi bir harici kütüphane gerektirmez)
